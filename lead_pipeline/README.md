# Solar Lead Profile Pipeline - Milestone 1

A reproducible, modular Python ETL pipeline designed to scrape public LinkedIn search results for solar-related professionals, clean and deduplicate the data, and score candidates. 

This is the first working milestone, focusing on the flow: **Python → Playwright → Visible Browser → LinkedIn → Search Results → Public Lead Info → CSV**.

## Why Playwright?
Playwright is used to automate Chromium in **visible mode** (`headless: false`). Because LinkedIn implements strict login blocks, CAPTCHAs, and anti-scraping checks, automated requests without a browser context usually fail immediately. 

Using Playwright in visible mode allows the user to:
1. Legally and visibly observe what Python is doing.
2. Complete manual authentication / login inside the browser if prompted.
3. Solve any CAPTCHAs or security challenges manually, permitting safe continuation without breaking terms of service.

## Installation & Setup

### 1. Install dependencies
First, set up your virtual environment and install the required libraries:
```powershell
# Create virtual environment
python -m venv lead_pipeline\.venv

# Activate the virtual environment
# Windows PowerShell:
.\lead_pipeline\.venv\Scripts\Activate.ps1
# Windows Command Prompt:
.\lead_pipeline\.venv\Scripts\activate.bat
# Linux/macOS:
source lead_pipeline/.venv/bin/activate

# Install requirements
pip install -r lead_pipeline/requirements.txt
```

### 2. Install Playwright browser binaries
Once the python dependencies are installed, download the required Chromium binaries:
```powershell
playwright install chromium
```

## Configuration (`config/settings.yaml`)

You can customize the pipeline behavior in `lead_pipeline/config/settings.yaml`:
- **`enabled`**: Enable or disable the LinkedIn scraping step.
- **`search_term`**: The keywords to search (e.g. `"solar sales manager"`).
- **`max_pages`**: Max pagination depth.
- **`delay_seconds`**: Throttling delay between pages (retains human-like behavior).
- **`headless`**: Runs with the browser window hidden if `true`. For the first run, keep `false` to see the browser visibly.
- **`max_results`**: Caps the number of records extracted.
- **`selectors`**: Key CSS selectors used to target the LinkedIn elements. If LinkedIn updates its markup, you can update these classes here without changing any code.

---

## How to Run

1. Verify `lead_pipeline/config/settings.yaml` has `headless: false` and `search_term: "solar sales manager"`.
2. Run the main orchestrator:
   ```powershell
   python -m lead_pipeline.src.main
   ```
3. Watch the Chromium browser open:
   - If you are redirected to the login page, **log in manually**. The command-line script will wait up to **5 minutes** for you to authenticate.
   - Once logged in, the browser will automatically load the search page and paginate according to your settings.
   - Collected results will print in the console and output to the CSV files.

## Output CSV Schema
Both raw and processed CSVs are saved in the `output/` directory:
- **`name`**: The profile's full name.
- **`title`**: Role title (e.g. "Solar Consultant").
- **`company`**: Organization name (parsed from the subtitle).
- **`location`**: Geographical location.
- **`source`**: Set to `"linkedin"`.
- **`search_term`**: Keyword query used.
- **`source_url`**: Profile link (with tracking parameters removed).
- **`scraped_at`**: Extraction timestamp.

## Pre-Call Solar Scoring Rules
The provisional solar score is designed specifically around the parameters in `lead-profiles.md` (which can eventually be joined with lead-form answers).
- Pre-call scoring only grades **3 out of 8** dimensions: `capital_readiness`, `technical_familiarity`, and `motivation`.
- The maximum possible pre-call score is **40/100**.
- Since scraped LinkedIn records do not have these answers, they are marked as **`provisional_score = pending`** and their `scoring_notes` will explicitly state that the scoring is pending questionnaire inputs.

## Legal & Access Policy
- **No Login Bypassing:** We do not programmatically automate or bypass LinkedIn credentials.
- **No CAPTCHA Bypassing:** No OCR or external CAPTCHA-solving services are used.
- **Public Data Only:** Only information visibly available on the search results pages is scraped. The script does not click into private profiles or extract restricted data.
- **Respect Rate-limits:** Pages are loaded slowly with configurable delays (`delay_seconds`) to remain compliant with standard request rates.
